# 表格导入导出

在母版的“Excel 导入导出”中导出 XLSX，用 Excel / WPS 修改后导回。浏览器可以直接读取和写入，不需要运行小助手。

先导出，再保存母版。母版记住每个单元格的导出基准：只改表格时采用表格，只改母版时保留母版，两边都修改时列为冲突，默认保留母版。导回前先看确认表，整次导入可以撤销、重做。表格缺少的作品不会删除；新增行可以留空 ID，也可以填写新的稳定 ID。已有作品的 ID 不要改。

`表格模板.xlsx` 是空模板，生成命令是 `python3 -I tools/make_template.py`。普通列可直接填写；JSON 列可以留空，需要多项内容时填写有效的数组或对象，例如别名写 `["示例别名"]`。资料编号和目录编号是两个独立字段，来源可以是 Steam、Bangumi 或自己配置的任意来源。

XLSX 包含以下工作表：

| 表 | 用途 |
|---|---|
| 作品 | 名称、版本、版本类型、标签、资料编号、来源状态、人工字段、封面网址等；JSON 扩展列保留其他记录字段。 |
| 合集 | 合集名称、资源链接和完整合集 JSON，作品稳定 ID 可以保存在合集配置中。 |
| HTML设置 | 常用设置与完整设置 JSON。只改普通设置格时，不会被未修改的完整 JSON 覆盖。 |
| 说明 | 使用提示。 |
| 来源配置 | 母版的 `sourceConfig`，包含启用状态和自定义资料。 |
| 目录定位 | 每个合集的已导入文件夹 JSON，离线清单；可选分享扫描另由设置启用。 |
| 分区 | 一行一个“目录 ID → 分区名”关系，支持同一作品出现在多个分区。 |
| 项目配置 | 个人标记、名单、榜单、参考网站等项目设置；大块内嵌图片及阅读器模板仍通过母版保存。 |

导出的来源配置可能含使用者自己填写的 API key；这是本机表格的完整配置往返。向别人发送前请清理凭据，或仅导出作品 CSV。公开演示与空模板不含凭据、分享链接和第三方图片。

CSV 是单张作品表，不携带合集、完整设置、目录定位或项目图片。支持 UTF-8、引号、逗号和单元格内换行。导入时可以映射自己的列名；未映射的非空标题列保存在“自定义字段 JSON”中。CSV 和 XLSX 使用同一套变更确认、三方比较、稳定 ID 与撤销流程。不要把 CSV 当完整项目备份。

小助手另保留任意表格列映射的批量导入接口；它只读取使用者提供的文件。复杂旧工作簿的专用列名与私人工作表预设没有内置，可用列映射或先整理为通用模板。
