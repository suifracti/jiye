# 来源和自定义网站

所有联网来源默认关闭。先在母版的「来源设置」启用，再由「抓取资料」「补编号」或「今日例行」触发。普通浏览和表格处理不需要来源接口。

## 内置与扩展来源

- Steam：填自己的 Web API key，使用官方名称目录；返回名称、appid 和商店链接。接口不提供简介/封面，使用手填、自选图片或获准使用的 JSON 补充。
- Bangumi：启用后使用公开 API 搜索及按编号查详情，保留来源。图片地址的返回不代表获得离线分发许可。
- 自定义 JSON：在来源设置中填写列表。资料保持离线，可添加多个来源。例如：

```json
[{"key":"library","name":"我的资料库","enabled":true,"detail_url":"https://example.invalid/items/{id}","records":[{"source_id":"demo-entry","name":"虚构条目","summary":"自制资料示例","url":"https://example.invalid/items/demo-entry","metadata_license":"自有资料"}]}]
```

在资料编号里填 `library:demo-entry`，或在「补编号」批量粘贴对应编号。目录编号和来源编号各自独立；一种来源失败不会清空其他来源的结果。

开发者可继承 `src/sources/base.py` 的 `Source`，实现 `_search(title)`、`_detail(source_id)`，返回 `result(...)` 的状态、候选及通用资料。用 `SourceRegistry.register(adapter)` 注册，默认保持关闭。自建来源应自行核对访问许可并保留 `metadata_license`、`cover_license`、`attribution_url`；不要加入绕过访问控制的实现。

## 自定义参考网站

在「参考网站」新增自己的合法站点和搜索模板，使用界面给出的占位符说明，先检测再搜索。默认没有资源站或账号。候选只作预览，用户选定才保存；可重选、撤销并查看来源。程序拒绝本机、私网及非常规端口地址，也会核对重定向地址。

## 分享目录定位

「合集」的「导入目录清单」接收按合集 ID 分组的 JSON。合集 ID 以当前母版导出的 XLSX 合集表为准。下面的标识与路径都是虚构示例：

```json
{"demo-collection":[{"fid":"demo-folder","name":"DEMO101","path":"/示例批次/DEMO101","has_files":true,"file_count":1}]}
```

导入目录清单后可以离线按编号匹配。也可以在「设置」打开默认关闭的「夸克扫描」，填写你自己的分享，再运行文件夹定位、大小统计、失效检测或换链接重扫。内置只读请求会获取运行期分享令牌并分页读取目录，不登录、不转存、不下载分享内文件；令牌不会写入进度缓存。自定义只读请求模板也是可选项。

目录大小覆盖子文件夹和分卷；只有完整读取后才判断条目缺失。限流、网络错误、取消与确实失效分别汇总，已完成结果可保留，中断目录扫描可续跑。真实分享访问本版尚未实测；服务接口可能变化。接口可用不表示取得访问或内容分发许可，请自行核对服务规则及自己的使用权限。

## 许可、请求与限制

适配器串行访问，默认间隔1秒，429/Retry-After后冷却，失败保留已有资料。Steam 官方条款、Bangumi 元数据许可、分享目录条款和逐次实测范围见 [来源许可](来源许可.md)。本地来源配置可能含凭据，母版及完整 XLSX 应自己保留；只把分发版交给读者。默认读者版不凭编号猜远程封面地址。

`tools/check_source.py` 默认不联网；只有显式 `--live` 才尝试一次详情，不下载图片、不保存正文。离线测试不等于外站可用，外站可用也不等于可以再分发图片。
