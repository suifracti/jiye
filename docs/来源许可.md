# 来源接口与素材使用

核对日期：2026-10-27。下面记录实际采用的官方接口、限制及替代入口；它不是对所有返回内容的统一授权。集页的 MIT 许可证只覆盖集页自身有权许可的代码。联网来源默认关闭；演示和测试仅含虚构内容。

| 来源 | 实现与默认值 | 元数据与图片 |
|---|---|---|
| Steam | 默认关闭。用户在本机提供自己的 Web API key 后，调用官方 `IStoreService/GetAppList/v1`，支持分页目录搜索和按 appid 查询名称、商店链接。 | API 条款允许按条件通过应用向最终用户提供个人使用的数据；不表示所有商店插画可随开源仓库或离线目录再次分发。官方目录接口不提供简介、封面，这两项可由手填、有权使用的 JSON 资料或自选图片补充。 |
| Bangumi | 默认关闭。使用公开 `/v0/search/subjects` 与 `/v0/subjects/{id}`，发送包含项目、版本、主页的 User-Agent。支持多种条目类型，返回候选、简介、封面地址和来源归属。 | 官方版权声明对条目信息说明 CC BY-SA，并对已有版权的作品另作处理。保存来源、遵守署名及相同方式共享条件；图片逐张核对，不能把 API 返回图片地址当成任意再分发的许可。适配器始终将图片再分发标记设为未确认。 |
| 自定义 JSON | 纯离线，来源 key 可自定义，提供名称搜索、按编号取详情、封面字段。也可注册实现相同接口的适配器。 | 提供者负责资料授权；可带 `metadata_license`、`cover_license`、`attribution_url`，不预置任何真实资料。 |
| 参考网站 | 默认列表为空。用户主动添加网站、检测接口或搜索模板，再预览候选、人工确认。只访问常规公开网页地址，阻止本机/私网、非常规端口及跳转到这些地址。 | 能访问、能预览和能下载均不代表可分享；用户应选自己创作或获准使用的图片，并保留来源。 |

Steam 官方条款规定日调用上限为 100,000 次，key 需保密；本实现每个来源串行、默认间隔 1 秒，并按 429 / Retry-After 冷却。这个间隔是集页自己的保守设置。Bangumi 本次核对未确认统一的固定请求配额，不宣称“每秒可调用多少次”；接口发生限流时暂停并保留原资料。搜索接口在官方文档中标为实验性，可能变化。

官方来源：

- [Steam IStoreService 文档](https://partner.steamgames.com/doc/webapi/IStoreService)、[Steam Web API 使用条款](https://steamcommunity.com/dev/apiterms)。旧 ISteamApps/GetAppList 已被官方标为弃用，集页不迁入商店非公开搜索、详情接口。
- [Bangumi OpenAPI](https://bangumi.github.io/api/)、[官方 schema](https://github.com/bangumi/api/blob/master/open-api/v0.yaml)、[User-Agent 建议](https://github.com/bangumi/api/blob/master/docs-raw/user%20agent.md)、[版权声明与开发者协议](https://bgm.tv/about/copyright)。

## 可选分享目录扫描

v1.1.0 的夸克扫描默认关闭。用户主动启用并填写自己的分享后，内置只读适配器取得运行期令牌、分页读取目录，可统计大小、检查分享或条目状态、换链重扫；也保留离线 JSON 目录和自定义只读请求模板。程序不登录、不转存、不下载分享文件，令牌不落入扫描进度缓存。

这是一项可选技术能力，不代表项目取得了服务商对自动化访问的统一许可。使用前自行核对 [服务协议](https://terms.alicdn.com/legal-agreement/terms/suit_bu1_uc/suit_bu1_uc202004211416_56889.html) 与自己的权限。只扫描自己的分享；不要将可访问、可预览等同于可以重新分发内容。离线测试验证分页、完整性、取消续跑和错误归类，本版没有真实分享网络验收。

参考网站默认空白，图片上传图床功能未提供。来源字段、人工编号、候选确认、自定义 JSON 和适配器入口用于使用者有权处理的资料。

## 验证范围

`python3 -I tools/test_sources_public.py` 使用虚构离线响应验证搜索、编号详情、冷却、人工优先、失败保留、JSON 扩展和目录分页/匹配；另验证 helper 的资料任务及列映射导入。这些离线结果不构成线上可用性或素材分发许可验证。真实请求记录另列如下。


### 2026-10-28 单次联网检查

新增 `tools/check_source.py`：不带 `--live` 时请求数为 0；只有显式启用才取一次官方编号详情，不下载图片、不打印或保存元数据正文。输出仅含来源、请求数、HTTP 状态、分类和返回字段名。Steam key 只能从本机 `STEAM_WEB_API_KEY` 环境变量读取，不接受命令行 key 参数。

- Bangumi：执行一次 `python3 -I tools/check_source.py --live --source bangumi --id 1`。尝试 1 次请求，未取得 HTTP 响应，分类为 `network_error`，返回字段为空。没有重试，没有取得或保存真实条目资料；线上详情可用性仍为**未验证**。
- Steam：未提供真实 API key，命令返回 `configuration_required`、请求数 0；真实联网为**未验证**。
- 默认离线命令返回 `disabled`、请求数 0。未下载封面，也未运行真实分享或参考站点扫描；素材再分发权限没有因此改变。
