# 集页｜项目记忆

用途：让接手者复用已存在的成果，保留旧行为，并准确记录新证据。这里不是第二份功能表或待办表。规则见 [AGENTS](../AGENTS.md)。

## 默认自动执行：不等用户提醒

在已有授权内由执行AI完成，用户不用说“查历史/以前做过/总结一下”，也不用记文件名或维护这份文档。

- 开工及改旧功能前，按自然称呼、症状、路径/符号和共享依赖查相关经验与实际实现，明确原有行为保留项；相关内容已读且未变就复用，不重读全库。
- 遇到异常、错误或找不到文件，在重试、推倒重写或让用户重新解释前，查旧修复、相关分支/别名及当前运行版本是否包含修复；同一症状不盲套同一根因。一次未命中不等于不存在。
- 重要问题解决、关键取舍或真实体验反馈出现时，当下把证据、原因确定程度、实际尝试/否定理由、实现定位与下次检查合并到原条目；交付前自行去重、修过时结论并读回，无新信息不硬写。
- 同类问题复发时，同时查“未记录/未找到/未采用/条件变了/修复不在当前版本/检查漏了”，修对应入口、经验或检查，不能只重修bug和追加“以后注意”。保护行为，不冻结代码。

这是任务内默认工作，不是无人会话时的后台服务；没有新建文件、审批、全量回归或定时器。权限/工具不足就说明具体未读/未写/未验范围，不假称完成。验收看下一次能否无提醒找回并应用经验，不看文档数量。数月全周期复盘另按AGENTS，不是日常归纳的前置条件。

## 增量维护

一条问题使用稳定编号与自然称呼，保存症状/来源、已证实或未知的原因、实际尝试及否定理由、实现与测试指针、版本和体验、下次触发/检查、被替代关系。相同问题更新原条目；有效方案也记录，不只积累禁令。

全周期复盘按 AGENTS 执行。只有实际处理、写入并读回后才更新覆盖点；相同 SHA/补丁和同义摘要去重，用户反馈无新提交也可以更新。私有历史不可访问时写缺口，不从代码反推用户满意或作者原意。
