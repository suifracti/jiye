# 集页使用说明

集页有三个部分：自己保留的母版、发给读者的分发版，以及按需启动的本机小助手。母版和分发版都是单个 HTML。示例目录没有实际资源，演示链接不可访问。

## 先选使用方式

自己的新目录从「空白母版.html」开始；「目录表-母版.html」提供48条虚构演示。直接双击母版进入文件模式。基本编辑、预览、撤销重做和浏览器表格导入导出不需要 Python。点保存时，浏览器可能允许写回已选文件，也可能下载一个新文件；以页面保存提示为准。下载的新母版要自己放到合适位置，重新打开确认即可继续使用。

需要直接写回、自动备份、资料任务或参考网站找图时，双击「启动空白目录」；查看演示则用「启动目录表」。小助手只监听本机，会打开母版页面。使用期间保留小助手窗口；可以从界面退出。它只允许一个运行实例，页面失联后会结束运行。

Windows 包若包含便携 Python，启动脚本会优先用它；否则需要本机 Python。macOS 需要可以运行 `python3`。如果系统要求确认运行本地脚本，按系统提示处理。

## 编辑作品

「待办」汇总需要完善的条目；「标签整理」统一别名与重复标签；「本地回填」仅用已有资料补空白，不覆盖人工内容。

在「整理名单」的表格里选择单元格，按 Enter 或双击编辑。Tab、Enter 和方向键用于连续输入。Shift 或 Ctrl 多选行后，可以批量修改、向下填充、删除或查找替换；误操作可撤销。

右侧详情保存条目的完整字段。目录编号用于自己找资源；资料编号指向某个资料来源，两者分别维护。资料编号可手填、批量粘贴、清空，重复或格式异常会提示。名字、别名、版本、大小、载体、版本类型、标签、归档批次、收录/更新日期和版本发布日期各有用途，不必塞进一个名称字段。

「新增作品」既可手填，也可粘贴一行发布文字再检查解析结果。目录编号可自行填写。多分区推荐直接为同一作品增加分区关系；其他版本保留为独立条目，方便比较和维护历史。

「体检」会列出缺字段、编号/日期不一致、合集或定位问题。可修的按提示回到条目编辑。缺少描述不等于不能发布；结构损坏、身份冲突等需要先处理的问题会另行提示。

制作备注保留在母版里，分发版不应带出。完整母版、工作簿和个人配置仍应由自己管理，不作为读者文件发送。

## 合集与目录定位

在「合集」维护分享链接；引用该合集的作品会跟着更新。单部作品也可以填写自己的入口。读者页会区分已确认直达、只有合集、有歧义和暂无入口，不把未知位置说成已完成。

夸克扫描是默认关闭的可选模块。在设置开启后，扫描自己填写的分享：定位目录、统计子文件夹和分卷大小、检查分享或条目是否失效、换链接后重扫。没有配置时显示去设置的提示。网络错误、限流和未读取完整不会被当成条目缺失；可保留部分结果，取消后续跑。

不启用网络模块时，也可以导入自己的目录 JSON，在本机按编号匹配，再确认有歧义或未找到的结果。标识与路径自定，例如：

```json
[{"fid":"demo-folder","name":"ITEM-0001","path":"/示例批次/ITEM-0001","has_files":true,"file_count":1}]
```

人工覆盖优先保留。服务接口及内容许可分别核对，详见 [来源许可](来源许可.md)。本版未完成真实分享的网络验收。

## Excel 与 CSV

需要在 Excel 或 WPS 批量处理时，先从当前母版导出 XLSX。作品的稳定 ID 用来对回条目，请保留；新增行可按导入提示处理。工作簿还包含合集、设置、来源配置及相关关系，适合完整往返。

改完导入后先看差异：

- 只有表格改了：可回填表格修改。
- 只有母版改了：保留母版修改。
- 两边改了同一项：显示为冲突，由你选用哪一份。
- 新增、陌生列或列错位：先确认映射及解析提示。

表格缺少某一行不应直接删除母版里的作品。确认后一次应用，必要时撤销。检查结果无误再保存母版。完整往返可按「导出→改表→导回并选择冲突→再导出→再导回」操作一次。

CSV 适合单张作品表。逗号、引号及多行内容可按标准 CSV 表达；它不包含完整的多表设置和关系。需要合集、导航、来源状态及跨分区关系时，使用 XLSX。

## 资料来源与按编号补全

来源默认关闭。打开「来源设置」，只启用自己需要的来源，再选作品运行资料任务。可按名称查找，也可按资料编号取详情。人工填写内容优先，查询失败保留已有资料；未找到、限流、未请求和其他失败会分开显示。

Steam 适配器需要自己的 Web API key，提供官方目录中的名称和商店链接；简介与封面可手填，或从有权使用的资料导入。Bangumi 返回资料和图片地址，但图片可见不代表可重新分发。自定义 JSON 可承载自己的来源编号、名称、说明及有权使用的图片信息。

密钥留在自己使用的本地配置中，分享前只导出读者版。不要在截图、反馈、工作簿或公开仓库里粘贴密钥。API、元数据和封面的许可分别见 [来源许可](来源许可.md)。

## 参考网站与封面

「参考网站」初始为空。添加站点或搜索模板，检测状态后再找图。可以启停、排序、删除站点；地址变化后重新检测。

候选图片只作为待确认结果。看清作品对应关系和来源，选择后压成小图保存，来源记录与修改可以撤销；不合适可重选。也可以直接选本地图片、粘贴或拖入自制图片。

全局封面开关控制是否显示图片，单部作品也可关闭。默认不会凭来源编号猜测远程封面地址；外部图片需明确启用，随机背景还需配置图源并打开背景开关。没有图片时使用配色和名称首字。

导出分发版时可选离线带图，先看大小预估和进度。跨域或下载失败会单独提示；检查导出结果，必要时换成本地有权使用的图片。只有自己的图片或明确获准分享的图片才应嵌入后分发。

## 今日例行

「今日例行」可以一键开始，也可分步运行；没有启用任何来源时，先显示去设置的提示。它把近日期条目的可选目录定位、已启用来源资料与编号补全、参考网站找图放在一次结果里。各步骤独立显示结果；未配置、近期已查过、限流和失败不会冒充成功，也不清空旧资料。

先看分步汇总，有候选图就人工选择。点「应用并保存」后把本轮结果记作一次修改，可撤销；它也会保存当前其他未保存的编辑。保存失败时保留结果并允许重试，不需要重复应用。

## 展示、榜单和月度名单

设置里可以改主题、头图、字体、字号、图片卡、工具箱和导航。说明卡及联系卡都有自己的标题、图片和目标地址；没填地址也会显示相应的未配置说明。导航可改名、排序、显示或隐藏。

在设置里自定义版本类型名称和颜色，默认仅“默认”。作者、分类、载体等字段可以改显示名称或隐藏；稳定字段键保持不变，Excel 导入不受改名影响。顶部提示可选复制，默认空白；最新版链接留空时隐藏，旧目录提醒默认0天关闭。附加标记按「显示名称｜标签」每行一个，可以任意增减。实际数据里的自定义值仍可用于检索和筛选。

预览使用和分发版相同的读者代码，可以切桌面或手机宽度；点预览区域可回到相应设置。改完保存，再检查导出结果。

榜单可分档位加入作品、填写分数和短评、调整顺序，发布后在读者页点击查看。旧图片榜单可使用自己有权使用的图，框选区域绑定作品。月度名单支持 TXT 导入、待匹配人工绑定、保留分组和标记，以及文字或图片导出。

## 导出与升级

当前导出发布整个目录；分区/选中发布是尚未实现的规划项。需要一份筛选结果表时，可在读者页使用「导出结果」。检查「本期变化」：有上一版时比较新增、版本、入口、说明和移除；没有上一版就明确说明没有比较基准。确认后导出分发 HTML，读者不需要小助手。

升级时把新包解压到新文件夹，运行「升级母版」选择自己的旧母版。新包里的目标文件会先备份，再把自己的内容与新程序组合。旧母版自己保留；不要直接用演示数据覆盖自己的目录。

## 给读者的说明

搜索支持多关键词、别名、编号、版本、拼音和假名归一；默认不搜长更新日志，勾选「含更新日志」后才包含。分类、载体、版本类型、标签、日期、作者和个人状态可以组合筛选，常用条件可以保存。

读者可切列表、紧凑版本条和封面墙，收藏、写备注、标记看过或隐藏、对比多个版本。拿取清单按合集分组，可复制整组说明；「已拿到」只是自己的勾选，不是实际下载进度。

个人数据保存在当前浏览器。换设备前用 JSON 备份，或复制收藏码；旧备份由读者主动导入，无法确认的条目留在待匹配，不强行绑定。同一目录升级时保持目录身份，可继续匹配稳定 ID。

## 遇到问题

先保留自己的母版备份，再描述所处模式、浏览器和操作步骤。尽量用可公开的合成条目复现；不要贴真实分享链接、提取码、密码、密钥或整份个人母版。哪些操作已经验证、哪些设备或外站尚未验证，见 [功能保留对照表](功能保留对照表.md)。
